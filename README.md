# 💸 MonoBot — фінансовий совість з характером

Telegram бот який аналізує витрати з Monobank і не боїться казати правду.

## Швидкий старт

### 1. Отримай токени

**Monobank API:**
- Відкрий додаток → Налаштування → Other → API → "Отримати токен"

**Telegram Bot:**
- Напиши @BotFather → `/newbot` → слідуй інструкціям

**Anthropic API:**
- Зайди на https://console.anthropic.com/ → API Keys → Create Key

### 2. Встанови залежності

```bash
cd monobot
pip install -r requirements.txt
```

### 3. Налаштуй .env

```bash
cp .env.example .env
# Відкрий .env і заповни всі три токени
```

### 4. Запусти

```bash
python bot.py
```

## Команди бота

| Команда | Що робить |
|---------|-----------|
| `/sync` | Завантажує транзакції за 30 днів |
| `/sync 7` | Завантажує за 7 днів |
| `/stats` | Статистика місяця |
| `/week` | Статистика тижня |
| `/categories` | Детально по категоріях |
| `/roast` | 🔥 Жорсткий розбір витрат |
| `/advice` | 💡 Конкретні поради що скоротити |

## Нотатки

- Monobank API дозволяє 1 запит на хвилину — `/sync` може йти довго для великих діапазонів
- Транзакції зберігаються локально в `monobot.db` (SQLite)
- Класифікація по MCC кодах — безкоштовна, Claude API використовується тільки для невідомих транзакцій
- `/roast` і `/advice` використовують Claude API (платно, але дешево)
